# Level Editor

Place units, buildings, trees, rocks and wrecks on a BAR map with the mouse, generate armies and mazes, build tower defense, capture the flag or reclaim the fame levels, save everything and turn it into a scenario for the official game. The result of a level is a `unitloadout` list (the format of BAR scenarios).

This manual describes the editor part by part. The short version for newcomers is in the [main README](../README.md); every button also has a tooltip and the **?** button shows all keys on the screen.

## Setup (once per computer, BAR must be installed)
1. Download or clone the repository and keep the folders `LevelEditor` and `shared` next to each other.
2. Run `install_editor.bat`. It searches BAR on all fixed drives (e.g. C:\Games, D:\Games, Program Files) and finds BAR and the engine, determines the installed game version, builds the extra game `data\games\LevelEditorMod.sdz` ("Level Editor", builds on the official BAR), creates the junctions `data\LevelEditor` -> `levels` and `data\LevelEditorBlueprints` -> `blueprints`, writes `start_level_editor.bat` and creates the desktop shortcut "BAR Level Editor". The setup also installs **LAN Play** (see the section at the end): a widget for the lobby of the game, the extra game of the scenarios `data\games\LevelEditorScenarios_<version>.sdz` ("Level Editor Scenarios <version>", the version is made of its files) and the junction `data\LevelEditorScenarios` -> `scenario\scenarios`, and it saves the official list of map checksums (md5, about 60 KB, `data\games\LevelEditorMapHashes.txt`; fetched online, only when it changed; offline the old list stays) with which LAN Play checks a map that a host sends. Close the game and the launcher before the setup (the lobby writes its settings when it ends).
3. After a BAR update or changes to the widget or gadget you do not have to run `install_editor.bat` again: `start_level_editor.bat` (and the desktop icon) compares a fingerprint of the files and the game version with the one of the last setup before every start and runs the setup by itself when they differ (not while a game is running).
4. Removing it again: run `uninstall_editor.bat` (it asks first). It removes the two extra games (`LevelEditorMod.sdz` and the own version of `LevelEditorScenarios_<version>.sdz`), the three junctions in the game folder, the LAN Play widget and the game widgets `shared_start.lua` and `scenario_briefing.lua`, switches the setting `loadLocalWidgets` of the lobby off again, and removes the desktop icon, `start_level_editor.bat`, the start script and the remembered files in `%LOCALAPPDATA%\BAR-Level-Editor` (`Last Map.txt`, `Online Maps Cache.json`, `Scav Units.txt`). Saved levels and blueprints stay in the folders `levels` and `blueprints`, the scenarios and maps received from other players stay in `%LOCALAPPDATA%\BAR-Scenario` (key 8 of the start menu cleans them), the official game is not touched. The game must not run. With `uninstall_editor.bat -WithSettings` the settings files of the editor in the game folder are deleted too, with `-Yes` the confirmation is skipped.

## Starting
Desktop shortcut "BAR Level Editor" (or `start_level_editor.bat`). The start menu is always shown (arrow up/down and Enter, or a digit key):
- **0** continue the last saved map (the state the editor saves every 2 minutes and when leaving as `_last`),
- **1** new level: choose a map (search while typing; the list contains all BAR maps from the internet, missing ones are only downloaded after the selection, offline only installed ones; the picture of the highlighted map with its size, players and terrain is shown next to the list, and with **Tab** and **Left/Right** you filter by size, number of players and terrain),
- **2** load an existing level (list from `levels`, with search),
- **3** build a scenario package (ZIP) from a level,
- **4** start one of the scenarios you built (always with the current scripts of the editor, so an old scenario is never out of date; choose it from the list, then how to play it: **Single player**, **Host** a game for others in the same network (a lobby with a box per team: everybody who joins lands in a team and you move the players between the boxes with Tab, Enter and the arrow keys, then "Start game" or F5), **Join** one (you only enter the address) or **Split screen** (host and the other players all on this computer, one window each: you enter the number of players, 2 to 8, the windows share the screen in 2 x 2, 3 x 2 or 4 x 2 cells and the players are distributed in the same lobby); the starter of that folder runs, also for Tower Defense scenarios).
- **5** upgrade a scenario package: choose one of the built scenarios and it is built again from the level it came from (found by the ID in the saved scenario info of the level, otherwise by the name of the level), with the info saved in that level and without any question: the package gets the current starter, lobby and gadgets and the current units of the level (the same as key 3, without choosing a level). Handy after an update of the editor or a change of the level when you want to pass the ZIP on again.
- **6** play a level at once (single player, host, join or split screen): no package is built and nothing is saved into the level. The level is turned into a small temporary scenario (a "bundle": the start script and the gadgets it needs, data only) in the cache `%LOCALAPPDATA%\BAR-Scenario\Cache\<hash>`. The host offers it in the lobby; **a joiner chooses "Join" and the address and gets the scenario from the host through the lobby** (or from their own cache if they had it already, the same level gives the same hash), so only the editor has to be installed on every computer. Programs that run on the computer itself are never taken from another computer: the bundle holds `scenario.txt` and Lua scripts that run only inside the game engine (gadgets, game widgets), anything else in it is refused.
- **7** (after an empty line) switch the Scavenger and Raptor units of the Place menu on or off (off at the start, the game start takes about 10 seconds longer when on; a level that holds such units switches them on by itself).
- **8** clean up: a list of your levels and built scenarios and of what came from other players (scenarios and maps in `%LOCALAPPDATA%\BAR-Scenario`, other versions of the extra game \"Level Editor Scenarios\"), with size and date; Space marks, A marks all of a kind, Enter removes after a question. Your own levels and scenarios go into a `_trash` folder next to them (nothing is deleted for good), what came from others is deleted (it is fetched again when needed). The maps of BAR itself are never offered. Old things of other players also go by themselves when the menu starts (scenarios not used for 30 days, maps not used for 60 days or beyond 3 GB, half-finished downloads).
If a joiner has not got the map nothing is asked: in the same network as the host they get it from the host over the network, otherwise they download it from the internet (a map is 30 to 200 MB; it is kept in the cache `%LOCALAPPDATA%\BAR-Scenario\Cache\Maps`, not in the data folder of the game). A map that comes from the host is checked against the hash and the size of the official map service first (so a changed file of a host is refused); a map of your own, which the service does not know, is only checked against the host's hash. Everybody plays the host's game: the scenario and its Lua files (gadgets and game widgets, which run only inside the game) come from the host, so the gadgets of a joiner may be older or newer. Only the lobby version has to be the same everywhere (the start menu shows it in its first line); a joiner with another one is refused with the note to update the Level Editor by hand (nothing that runs on the computer itself is ever taken from another computer).

When loading, the editor starts on the saved map and sets up the units automatically (via `levels\_autoload.txt`).

## The screen
In editor mode (game option `leveleditor=1`) no /cheat and no /globallos are needed. Everything is free and finished instantly. Legion, the extra pack and release candidates are on. At the start only the commander stands there; the builders of all factions are created with **Ctrl+D** at the mouse pointer (they are tools and are not saved in the level). The unit limit is raised to 32000 (`maxunits`). The menu follows the UI size slider of the BAR settings.

- **Moving the menu:** drag the title row ("Level Editor") with the left mouse button, the whole menu moves with the strip at the left and the button column. A right click on the title puts it back. The position is remembered.
- **Button column at the right edge** (top to bottom): **V** collapse the menu, **O** settings, **I** scenario info, **T** teams (human or AI, alliance, start resources), **?** help; **P** Place, **G** Generate, **TD** Tower Defense, **CF** Capture the Flag, **RF** Reclaim the Fame; **XL / XR / XC** area attacks (experimental); **FX / FD** make buildings in a rectangle indestructible / destructible again.
- **Strip left of the menu** (top to bottom): **W** (write/overwrite, see Placing), **DL / DR / DC** (delete along a line, in a rectangle, in a circle), **L / R / S** (rotate left / right, mirror; only with a selection), **N** (neutral), one button per team with its current unit count, **G** (Gaia: no owner, enemy to everyone).
- **Teams:** the game has ten teams (0 to 9), you choose the team with the team buttons; selected units get the team with a click on a team button. A **right click** on a team button chooses its **alliance** (ten colors; the button gets a frame in that color, teams of one color are allies, all others enemies); human or AI and the start resources are on the page **T**. Only teams 0 and 1 start with a commander, a team can hold 3150 units. **G** (Gaia) has at most 500 units, a limit the engine fixes (the tooltip of the button says so); for many neutral units use **N** instead.
- **Cheat and god mode:** at the start the editor switches on the cheat mode and the god mode for all teams (the game shows "Cheating is enabled!"), so units of every team can be selected and commanded (see Selecting).
- **Right click** anywhere (also over the menu and the buttons) ends every mode: placing, delete, maze, generate, area attack. Without a mode it is the order of the game for the selected units (move, attack, ...); a left click on the ground clears the selection. Starting a Tower Defense or Capture the Flag test ends every editor mode. The markers of Tower Defense (spawn point, goal, waypoints) and Capture the Flag (collection and flag points) stay visible in the world with their pages closed.
- **Help:** the **?** button shows the keys and short explanations as a board on the screen; a click closes it. Chat commands are only left for diagnosis: `/led_help` shows the short version and the topics (`/led_help <topic>` explains details: `start`, `keys`, `place`, `units`, `blueprint`, `save`, `team`, `edit`, `features`, `search`, `scenario`, `build`), `/led_clear` clears the map, `/led_ghost` shows the state of the 3D preview.

## Placing (button P)
The Place menu has the sub-tabs **Recent** (recently chosen blueprints and placed units), **Units**, **Features** and **Blueprints**.
- **Units tab:** choose faction (Armada, Cortex, Legion, **Scavengers**, **Raptors**), group (buildings, air, vehicles, bots, hover, ships) and tech (T1 to T3). The units appear with their pictures; hovering shows a rotating 3D view with the information **under it**: name (code), the description, metal, energy and the **Eco time** (how long your current income needs to produce this cost; worst case, the stock is not counted; `-` without income), the health, for a unit that shoots a line like `DPS 41 = 0.26 shots/s x 157 dmg` (with lines for metal and energy per shot if the weapon needs them), then one line each for range, LoS (line of sight), speed, radar, radar jammer, sonar and sonar jammer (only what the unit has) and the damage to the surroundings when it is destroyed and when it self-destructs. For a blueprint the costs are the sums (marked "Sum"), the speed is that of the slowest unit (marked "Min") and the other values the largest of its units. A faction, group or tech button with nothing behind it is slightly red, so you see at once which tabs are empty. Click one, then left click on the map places it (blue outline), right click ends, **[** and **]** rotate. The list comes straight from the game, so it also includes Legion, the extra pack and custom units.
- **Scavengers and Raptors:** the Scavengers are the `_scav` copies of all units, the Raptors the `raptor_*` units. The Scavengers list holds the units of all three factions: first all of Armada, then Cortex, then Legion, then their own units, each in the usual order (economy, factories, turrets, utility, water); the walking Raptors are under Bots. Nobody steers them: a level has no Scavenger or Raptor AI, so they stand where you put them until a player gives them orders. They exist in the game only with the game option `forceallunits`, which makes the start about 10 s longer: it is **off** by default. Switch it on in the start menu (**key 7**, remembered); a level that holds such a unit carries the option (`requiredmodoptions`), so loading it, scenarios, tests and LAN games switch it on by themselves. Test level: `test-data\levels\scav_test.lua`.
- **Restrictions (red X):** one list for the whole level of what the player may **not build** in the game (Start, finished scenario; the editor itself can always place everything). A small **X** in the upper right corner of every unit picture forbids that unit (it is dimmed with a big red X; click the X again to allow it). The X in the faction, group and tech buttons forbids all units in it right now: faction = all of its units, group = all units of that group of the chosen faction, tech button = all units of that tech level in all factions and groups (as the editor counts it: half levels count down, Epic units are T3). Every X is only the shortcut for a list of single units: it is on exactly when all of them are forbidden, so it goes off by itself when you allow one of them, and it comes on by itself when you forbid the last one. The Tower Defense page shows the same list (only the towers, economy structures and radars that matter there): forbidding or allowing there changes the Place menu and the other way round. The list is saved in the section `restrictions` of the level file and works in every mode (Tower Defense, Capture the Flag, plain levels): the gadget `unit_restrictions.lua` refuses the build orders and tells the build blocking of BAR, so the forbidden units are greyed out in the build menu of the player. The list holds for every team, also for the computer players (they do not know it and may get stuck trying); only human teams get the message "Not allowed".
- **Search:** one field at the top of the Place menu searches recent items, units, features and blueprints at once (words of the description or the code; all words must match; for blueprints also the units inside). The tabs show the number of matches. The field turns reddish while it contains a text. Enter = done, Esc or X = clear; a click on a faction/group/tech/feature-kind button ends the search. All lists have a scrollbar at the right edge (drag the thumb or click the track; the mouse wheel works as before).
- **Painting:** hold the left mouse button and move: with an armed unit or feature (also the structures of the Tower Defense list and the single wall pieces) one is placed after every footprint of mouse movement (plus the spacing); Ctrl+Z takes the whole stroke back. Blueprints are not painted.
- **Rows and rectangles:** **Shift + drag** places a row of the armed unit, feature or blueprint, **Shift + Alt + drag** a rectangle (all are placed on release); **Shift + mouse wheel** (or Alt+Z / Alt+X) changes the spacing.
- **W (write):** green = on (default) decides what happens when something is placed where something already stands (units, features, single pieces, rows, blueprints, pasted copies, corridor wall pieces): **on** overwrites, i.e. what is in the way is deleted (units and features under the footprint, in the same undo step: Ctrl+Z brings it back); **off** places nothing on an occupied spot (a blueprint is placed only partly). Generate always looks for another free spot of the area instead (so you may get fewer units in a crowded area).
- **Features** (trees, rocks, crystals, wrecks) are placed like units; Del deletes the one under the mouse. The tab **Crystals** holds the crystals of Reclaim the Fame (small, medium, large, in many colors).
- Air units appear in the air when placed and loaded (when loading with the saved height, otherwise cruise height) and stay in flight mode. Air units that stood on the ground when saving are loaded landed.
- Nuclear silos and other units that stockpile missiles start **loaded** (10 missiles) when you place or generate them. The missiles are not saved in the level: a scenario built from it starts with empty silos.
- Resurrected units are set to hold position.

## Blueprints
- Select units and press **Create** (P → Blueprints): the layout is saved in the folder `blueprints`. The **Blueprints** tab shows tiles with preview pictures (unit positions in team colors, air units with a white border), the name, the number of units and the total cost (`M` metal, `E` energy). Click a tile, then left click on the map places it centered at the mouse pointer (outline preview; with the saved teams, or for the team chosen on the left), right click ends, the mouse wheel scrolls. The list comes from the folder `blueprints` (and from `_index.txt` as a fallback).
- **Sorting:** drag a tile with the mouse and drop it elsewhere (order in `blueprints\_order.txt`; off while a search is active).
- **Deleting:** small x at the top right of the tile, click twice. The file moves to `blueprints\_trash` and can be restored by hand.
- **Renaming:** double click on the name, type, Enter. Esc cancels.
- The blueprint menu is available right at the start of the editor. You save the whole level with Ctrl+S (blueprints only contain the units you selected).

## Generate (button G)
The Generate page has the sub-tabs **Units** and **Maze**. For the team chosen on the left (N = neutral):
- **Units:** choose faction, type (units, buildings, turrets, air, ships; several possible), tech T1-T3 and the count (input field, 1 to 2000), press **Rectangle** or **Circle** (circle: drag from the center outwards) and drag the area on the map; random units appear in it (there is no separate Generate button: the shape button starts it, the same button again or a right click ends it). Ctrl+Z undoes it.
- **Maze:** choose faction, material (dragon teeth or walls) and the **corridor width** (32, 64, 128, 160 or 192 Elmo; the same widths as for Tower Defense corridors), then press **Rectangle** or **Circle** and drag: a random maze appears in it, with the entrance top left and the exit bottom right. The key **M** cycles the maze mode (dragon teeth, walls, off).

## Selecting, editing and deleting
- **Selecting:** the editor switches on the cheat mode and the god mode for all teams at the start (`/godmode 3`), so you select units of every team like your own: click or drag a rectangle, enemies too. The command menu of the game appears for them and their orders work (move, attack, patrol, stop, build ...; the orders of units of other teams are forwarded to the gadget). Delete, blow up, assign to a team, copy and blueprints use the selection.
- **Del** deletes the selection, without a selection the unit, wreck or feature under the mouse pointer. **Ctrl+B** blows up (wreck stays). The buttons **DL**, **DR** and **DC** delete everything along a dragged line (a corridor 80 Elmo wide), in a dragged rectangle (key **D**) or in a dragged circle: units, wrecks, features.
- **Copy and paste:** **Ctrl+C** copies the selected units/buildings (without a selection the unit at the mouse pointer), **Ctrl+X** cuts, **Ctrl+V** pastes them centered at the mouse pointer, with team, rotation and height, any number of times; the clipboard lasts until you quit the editor.
- **Moving:** **Alt + drag** on a selected unit moves the selection, **Alt + drag** on a feature (tree, rock, wreck) moves that feature; the **arrow keys** move it by one grid step (up = north). **[** and **]** rotate a stamp; **L / R / S** rotate and mirror a selection.
- **Undo / redo:** **Ctrl+Z** / **Ctrl+Y** for placing, deleting, moving, rotating, generating, team changes, features and Tower Defense route changes.
- **Indestructible buildings:** **FX / FD** (drag a rectangle) mark buildings as indestructible or destructible again (only buildings; in every scenario, whatever the game mode); the flag is saved in levels, blueprints and the clipboard.
- The shortcuts only work in the Level Editor; in the chat input and in the search fields of the menu they do not apply.

## Levels and settings
- **Ctrl+S** writes `levels\<name>.lua` (units and features, so also wrecks and trees) under the current name, otherwise as a new `level_001` ... Besides the units the file has the sections of the pages: `towerdefense`, `capture` (Capture the Flag), `reclaim` (Reclaim the Fame), `restrictions` (what the player may not build) and the scenario info. Loading takes over only the fields the editor knows; nothing old is kept and saved again (there is no backward compatibility).
- The button **O** opens the settings (with more than 3 columns the pictures of the menu get smaller; the menu itself keeps the width it has with 3 columns): the **grid** size (1 = free, 4, 8, 16, 32, 64 Elmo), the **unit limit** (500 to 32000; saved in the level file as `unitlimit` and used as `maxunits` by the scenario package; the editor itself always runs with 32000), columns and rows for the blueprint view and for the units view (default 3 columns and 4 rows each). The values are stored in `LuaUI\Config\LevelEditorUI.lua` in the game folder. Below them is the level list: **Load**, **Save** (a second click confirms) and **Save as new**; loading clears the map and sets the level up again. `/led_clear` only clears up.

- `levels\` - saved levels; `blueprints\` - saved layouts
- `..\shared\` - shared code of the Level Editor and the BluePrinter (blueprint view, units menu, settings, 3D preview, rules); the folder must lie next to `LevelEditor`, `install_editor.bat` packs the files into the extra game.

## Game modes
A level can be one of three game modes; they exclude each other (ticking one switches the others off). Each has a page of the editor (buttons **TD**, **CF**, **RF** in the button column at the right), a test run (**Start** / **Stop**), and becomes a scenario with everything on its page. All the settings are on the page of the mode:
- **Tower Defense** (button **TD**): waves of enemies walk a route to a goal, the player builds towers next to it. [Read more](game-modes/tower-defense.md)
- **Capture the Flag** (button **CF**): flags are carried to the collection point of a team and earn metal; for human against human. [Read more](game-modes/capture-the-flag.md)
- **Reclaim the Fame** (button **RF**): crystals pay points to the construction units that reclaim them; the first team at the score limit wins; for human against human. [Read more](game-modes/reclaim-the-fame.md)

## Making a scenario from it
In the game itself: the button **I** in the button column at the far right next to the menu opens the scenario info: title, author, summary, briefing (Shift+Enter = new line), win condition, grace period and ID. Click text fields and type (Enter done, Esc cancel), the other fields change with every click. The info is written when the level is saved; there is no save button on this page (Ctrl+S saves). The scenario builder does the rest (see below). A level with one of the three game modes (Tower Defense, Capture the Flag, Reclaim the Fame) becomes that kind of scenario; with restrictions it also carries them.

The button **T** (between I and ?) is the table of the **teams** (the editor game has ten, 0 to 9): per team **Human** or **AI** (a click switches), the AI (a click opens the list: NullAI, BARb, CircuitAI, CircuitAI easy, SimpleAI, SimpleDefenderAI, SimpleConstructorAI, Scavengers, Raptors), the **alliance** (a click opens ten colors; teams with the same color are allies, all others are enemies) and the start metal and energy. The alliance is also chosen with a **right click on a team button** at the left of the menu: the button gets a frame in the color of the alliance. Everything is saved with the level (Save). The AI takes effect in the scenario package (and the AI of team 1 at the next start of the editor); a running game cannot change an AI. Only teams with units are part of a scenario. In Tower Defense every AI team is an enemy and the first AI team spawns the waves.
In the start menu **key 3** (create a scenario package from a level): choose a level; the script lists the values stored in the level and asks only for the title (Enter keeps it) and the name (ID) of the scenario, then builds a scenario that others can play with the official BAR (folder and zip in `scenario\scenarios`; an existing scenario of that name is only overwritten after a question). The info (title, briefing, win condition, grace period, ID; human or AI, alliances and start resources come from the page T) is stored in the level and changed in the editor with the I button. Details in `scenario\README.md`.

## LAN Play (play in the same network, with the lobby of the game)
**LAN Play** is an entry in the main menu of the game, right below Multiplayer. It gives you the multiplayer battle room of the game (map, options, AIs, teams, chat) for a game with computers in the same network, without the lobby server. The normal Multiplayer is not changed. It is a widget for the lobby (`lan_lobby\lan_lobby.lua`, installed by `install_editor.bat`); it only needs TCP port 8453 (lobby) and 8452 (the game) between the computers (Windows may ask once for the firewall). Only computers of the local network (or of a VPN such as Tailscale or Hamachi) can join.
- **Name:** the page shows your name (the account name of the game; you need not be logged in); change it in the field if you like.
- **Host:** open **LAN Play**, press **Host a LAN game**. You are in the battle room. Choose the map and the options as in the normal multiplayer room, then press Start. Others can join while you are in the room.
- **Join:** open **LAN Play**: the page looks for games in the network by itself every few seconds (a /24 network, e.g. 192.168.1.x); click a game to join it. Or type the address and press Join. Whoever hosts does not look for games (so you never find yourself).
- **Leave:** leaving the battle room (or **Leave LAN play**) takes you back to the LAN Play page and logs the lobby in to the normal server again. After a game you come back to the LAN Play page.
- **Custom Scenario:** the host has a button **Custom Scenario** at the top left of the room. It lists the scenarios you built (`scenario\scenarios`) and the entry "Official map (no scenario)". A scenario sets its map and its teams (the teams cannot be changed while it is chosen), and every player who joins plays in the team of the scenario's player (cooperative against the AI of the scenario). Choosing an official map brings the free teams back. The Level Editor setup builds the game "Level Editor Scenarios" (the gadgets of the scenarios, with a version made of its files) on every computer; a joiner who has not got the host's version is asked and gets it from the host before the start, as a file of its own (their own version stays).
- **Copilot:** the host has a second button **Copilot** below **Custom Scenario** (both in the middle column of the room, under "Map Ready"). Inside every team (ally team) each human has a number 1, 2, 3 ... (by default everybody their own). A click on a player gives them the next number of their team; **humans with the same number are Copilots and play one player together** (one team of the game: all give orders to its units, one pool of resources, e.g. one fights at the front, one builds the base). The room says it in the chat ("PlayerB is player 1 of their team now and is Copilot with PlayerA."), the window shows "+ Copilot with ..." and the start announces the Copilots. In such a game the start positions of the map are used (the game of a shared team is started by the little widget `shared_start.lua` as soon as everybody has loaded, so nobody could place a start position first).
