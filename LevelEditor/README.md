# Level Editor

Place units, buildings, trees, rocks and wrecks on a BAR map with the mouse, generate armies and mazes, build tower defense levels, save everything and turn it into a scenario for the official game. The result of a level is a `unitloadout` list (the format of BAR scenarios).

This manual describes the editor part by part. The short version for newcomers is in the [main README](../README.md); every button also has a tooltip and the **?** button shows all keys on the screen.

## Setup (once per computer, BAR must be installed)
1. Download or clone the repository and keep the folders `LevelEditor` and `shared` next to each other.
2. Run `install_editor.bat`. It searches BAR on all fixed drives (e.g. C:\Games, D:\Games, Program Files) and finds BAR and the engine, determines the installed game version, builds the extra game `data\games\LevelEditorMod.sdz` ("Level Editor", builds on the official BAR), creates the junctions `data\LevelEditor` -> `levels` and `data\LevelEditorBlueprints` -> `blueprints`, writes `start_level_editor.bat` and creates the desktop shortcut "BAR Level Editor".
3. After a BAR update or changes to the widget or gadget you do not have to run `install_editor.bat` again: `start_level_editor.bat` (and the desktop icon) compares a fingerprint of the files and the game version with the one of the last setup before every start and runs the setup by itself when they differ (not while a game is running).
4. Removing it again: run `uninstall_editor.bat` (it asks first). It removes the extra game, the two junctions in the game folder, the desktop icon, `start_level_editor.bat`, the start script and the cached map files (`last_map.txt`, `maps_online_cache.json`). Saved levels and blueprints stay in the folders `levels` and `blueprints`, the official game is not touched. With `uninstall_editor.bat -WithSettings` the settings files of the editor in the game folder are deleted too, with `-Yes` the confirmation is skipped.

## Starting
Desktop shortcut "BAR Level Editor" (or `start_level_editor.bat`). The start menu is always shown (arrow up/down and Enter, or a digit key):
- **0** continue the last state (the editor saves every 2 minutes and when leaving as `_last`),
- **1** new level: choose a map (search while typing; the list contains all BAR maps from the internet, missing ones are only downloaded after the selection, offline only installed ones),
- **2** load an existing level (list from `levels`, with search),
- **3** build a scenario package (ZIP) from a level,
- **4** start one of the scenarios you built (choose it from the list; the starter of that folder runs, also for Tower Defense scenarios).

When loading, the editor starts on the saved map and sets up the units automatically (via `levels\_autoload.txt`).

## The screen
In editor mode (game option `leveleditor=1`) no /cheat and no /globallos are needed. Everything is free and finished instantly. Legion, the extra pack and release candidates are on. At the start only the commander stands there; the builders of all factions are created with **Ctrl+D** at the mouse pointer (markers ARMADA, CORTEX, LEGION; they are tools and are not saved in the level). The unit limit is raised to 32000 (`maxunits`). The menu follows the UI size slider of the BAR settings.

- **Moving the menu:** drag the title row ("Level Editor") with the left mouse button, the whole menu moves with the strip at the left and the button column. A right click on the title puts it back. The position is remembered.
- **Button column at the right edge** (top to bottom): **V** collapse the menu, **O** settings, **I** scenario info, **?** help; **P** Place, **G** Generate, **TD** Tower Defense, **CF** Capture the Flag; **XL / XR / XC** area attacks (experimental); **FX / FD** make buildings in a rectangle indestructible / destructible again.
- **Strip left of the menu** (top to bottom): **W** (write/overwrite, see Placing), **DL / DR / DC** (delete along a line, in a rectangle, in a circle), **L / R / S** (rotate left / right, mirror; only with a selection), **N** (neutral), one button per team with its current unit count, **G** (Gaia: no owner, enemy to everyone).
- **Teams:** you choose the team with the team buttons; selected units get the team with a click on a team button.
- **Right click** anywhere (also over the menu and the buttons) ends every mode: placing, delete, maze, generate, area attack. Without a mode it is the order of the game for the selected units (move, attack, ...); a left click on the ground clears the selection. Starting a Tower Defense or Capture the Flag test ends every editor mode. The markers of Tower Defense (spawn point, goal, waypoints) and Capture the Flag (collection and flag points) stay visible in the world with their pages closed.
- **Help:** the **?** button shows the keys and short explanations as a board on the screen; a click closes it. Chat commands are only left for diagnosis: `/led_help` shows the short version and the topics (`/led_help <topic>` explains details: `start`, `keys`, `place`, `units`, `blueprint`, `save`, `team`, `edit`, `features`, `search`, `scenario`, `build`), `/led_clear` clears the map, `/led_ghost` shows the state of the 3D preview.

## Placing (button P)
The Place menu has the sub-tabs **Recent** (recently chosen blueprints and placed units), **Units**, **Features** and **Blueprints**.
- **Units tab:** choose faction (Armada, Cortex, Legion), group (buildings, air, vehicles, bots, hover, ships) and tech (T1 to T3). The units appear with their pictures; hovering shows name and metal cost below the menu and a rotating 3D view. Click one, then left click on the map places it (blue outline), right click ends, **[** and **]** rotate. The list comes straight from the game, so it also includes Legion, the extra pack and custom units.
- **Search:** one field at the top of the Place menu searches recent items, units, features and blueprints at once (words of the description or the code; all words must match; for blueprints also the units inside). The tabs show the number of matches. The field turns reddish while it contains a text. Enter = done, Esc or X = clear; a click on a faction/group/tech/feature-kind button ends the search. All lists have a scrollbar at the right edge (drag the thumb or click the track; the mouse wheel works as before).
- **Painting:** hold the left mouse button and move: with an armed unit or feature (also the structures of the Tower Defense list and the single wall pieces) one is placed after every footprint of mouse movement (plus the spacing); Ctrl+Z takes the whole stroke back. Blueprints are not painted.
- **Rows and rectangles:** **Shift + drag** places a row of the armed unit, feature or blueprint, **Shift + Alt + drag** a rectangle (all are placed on release); **Shift + mouse wheel** (or Alt+Z / Alt+X) changes the spacing.
- **W (write):** green = on (default) decides what happens when something is placed where something already stands (units, features, single pieces, rows, blueprints, pasted copies, corridor wall pieces): **on** overwrites, i.e. what is in the way is deleted (units and features under the footprint, in the same undo step: Ctrl+Z brings it back); **off** places nothing on an occupied spot (a blueprint is placed only partly). Generate always looks for another free spot of the area instead (so you may get fewer units in a crowded area).
- **Features** (trees, rocks, wrecks) are placed like units; Del deletes the one under the mouse.
- Air units appear in the air when placed and loaded (when loading with the saved height, otherwise cruise height) and stay in flight mode. Air units that stood on the ground when saving are loaded landed.
- Nuclear silos and other units that stockpile missiles start **loaded** (10 missiles) when you place or generate them. The missiles are not saved in the level: a scenario built from it starts with empty silos.
- Resurrected units are set to hold position.

## Blueprints
- Select units and press **Create** (P → Blueprints): the layout is saved in the folder `blueprints`. The **Blueprints** tab shows tiles with preview pictures (unit positions in team colors, air units with a white border), the name, the number of units and the total cost (`M` metal, `E` energy). Click a tile, then left click on the map places it centered at the mouse pointer (outline preview; with the saved teams, or for the team chosen on the left), right click ends, the mouse wheel scrolls. The list comes from the folder `blueprints` (and from `_index.txt` as a fallback).
- **Sorting:** drag a tile with the mouse and drop it elsewhere (order in `blueprints\_order.txt`; off while a search is active).
- **Deleting:** small x at the top right of the tile, click twice. The file moves to `blueprints\_trash` and can be restored by hand.
- **Renaming:** double click on the name, type, Enter. Esc cancels.
- The blueprint menu is available right at the start of the editor. You save the whole level with Ctrl+S (blueprints only contain the units you selected).

## Generate (button G)
The Generate page has the sub-tabs **Units** and **Maze**. For the team chosen on the left (N = neutral):
- **Units:** choose faction, type (units, buildings, turrets, air, ships; several possible), tech T1-T3 and the count (input field, 1 to 2000), choose the **Area** (rectangle, or circle: drag from the center outwards), press **Generate** and drag it on the map; random units appear in it. Ctrl+Z undoes it.
- **Maze:** choose faction, material (dragon teeth or walls) and the **corridor width** (32, 64, 128, 160 or 192 Elmo; the same widths as for Tower Defense corridors), then **Generate** (Area as above) and drag: a random maze appears in it, with the entrance top left and the exit bottom right. The key **M** cycles the maze mode (dragon teeth, walls, off).

## Selecting, editing and deleting
- **Selecting:** the editor switches on the cheat mode and the god mode for all teams at the start (`/godmode 3`), so you select units of every team like your own: click or drag a rectangle, enemies too. The command menu of the game appears for them and their orders work (move, attack, patrol, stop, build ...; the orders of units of other teams are forwarded to the gadget). Delete, blow up, assign to a team, copy and blueprints use the selection.
- **Del** deletes the selection, without a selection the unit, wreck or feature under the mouse pointer. **Ctrl+B** blows up (wreck stays). The buttons **DL**, **DR** and **DC** delete everything along a dragged line (a corridor 80 Elmo wide), in a dragged rectangle (key **D**) or in a dragged circle: units, wrecks, features.
- **Copy and paste:** **Ctrl+C** copies the selected units/buildings (without a selection the unit at the mouse pointer), **Ctrl+X** cuts, **Ctrl+V** pastes them centered at the mouse pointer, with team, rotation and height, any number of times; the clipboard lasts until you quit the editor.
- **Moving:** **Alt + drag** on a selected unit moves the selection; the **arrow keys** move it by one grid step (up = north). **[** and **]** rotate a stamp; **L / R / S** rotate and mirror a selection.
- **Undo / redo:** **Ctrl+Z** / **Ctrl+Y** for placing, deleting, moving, rotating, generating, team changes, features and Tower Defense route changes.
- **Indestructible buildings:** **FX / FD** (drag a rectangle) mark buildings as indestructible or destructible again; the flag is saved in levels, blueprints and the clipboard.
- The shortcuts only work in the Level Editor; in the chat input and in the search fields of the menu they do not apply.

## Levels and settings
- **Ctrl+S** writes `levels\<name>.lua` (units and features, so also wrecks and trees) under the current name, otherwise as a new `level_001` ...
- The button **O** opens the settings: the **grid** size (1 = free, 4, 8, 16, 32, 64 Elmo), the **unit limit** (500 to 32000; saved in the level file as `unitlimit` and used as `maxunits` by the scenario package; the editor itself always runs with 32000), columns and rows for the blueprint view and for the units view (default 3 columns and 4 rows each). The values are stored in `LuaUI\Config\LevelEditorUI.lua` in the game folder. Below them is the level list: **Load**, **Save** (a second click confirms) and **Save as new**; loading clears the map and sets the level up again. `/led_clear` only clears up.

## Files
- `lvl_level_editor.lua` - widget (controls, saving, loading)
- `unit_level_editor.lua` - gadget (places, deletes, blows up, build mode)
- `td_waves.lua` - gadget of the Tower Defense waves and the build restrictions (also used by Tower Defense scenarios)
- `ctf_game.lua` - gadget of Capture the Flag (flags, collection points, reward; also used by scenarios)
- `led_ctf.lua` - the Capture the Flag page of the widget (loaded by the widget)
- `help_texts.lua` - texts of the help board (?) and of `/led_help`
- `choose_map.ps1` - start menu and map selection (all maps, download after the selection), writes `editor_script_installed.txt`; `maps_online_cache.json` is the cached map list
- `install_editor.bat` / `install_editor.ps1` - setup (`-Quick`: only the extra game, used by the start script)
- `ensure_installed.ps1`, `editor_stamp.ps1` - called by `start_level_editor.bat`: fingerprint of the packed files and the game version, runs the setup when it changed
- `uninstall_editor.bat` / `uninstall_editor.ps1` - removal (levels and blueprints stay)
- `start_level_editor.bat` - start (created by the setup)
- `check_links.ps1` - called by `start_level_editor.bat` before every start: points the two junctions to the `levels` and `blueprints` folders again if the project folder was moved
- `scenario\` - scenario builder (start menu key 3, see `scenario\README.md`)
- `levels\` - saved levels; `blueprints\` - saved layouts
- `..\shared\` - shared code of the Level Editor and the BluePrinter (blueprint view, units menu, settings, 3D preview, rules); the folder must lie next to `LevelEditor`, `install_editor.bat` packs the files into the extra game.

## Tower Defense
The button **TD** (in the button column at the right, below **P** and **G**) opens the tower defense page. Waves of enemy land units walk from a spawn point through waypoints to a goal; the player builds towers next to the route.
- Tick **Tower Defense** to mark the level; with it ticked (or the TD page open) the title of the menu reads "Level Editor - Tower Defense". All settings are saved with the level (Ctrl+S, autosave) in an own section `towerdefense` of the level file.
- **Walls**: choose the material (**Teeth** or **Walls**); the button **Single** places single wall pieces: every click on the map places one, hold the mouse button and move it to place a piece in every grid cell. **Corridor (walls on both sides)**: **Line** = click the points on the map, then **right click** builds the walls on both sides; **Free** = hold the left mouse button and draw any line, the walls appear when you let go. The mode stays on after every corridor, so you can draw the next one at once; **right click** ends it. Ctrl+Z undoes a corridor, so a wrong one costs nothing. The wall pieces are **indestructible**: nothing damages them and builders cannot reclaim them (higher tech enemies would shoot a way through otherwise; they are marked `indestructible = true` in the level file; you can still delete them with Del). **Corridor width**: 32, 64, 128 (default), 160 or 192 Elmo, the same widths as for the maze of the Generate page. Bends are closed: an arc of wall pieces fills the outside of every corner.
- **Route**: **Spawn** (green circle) and **Goal** (red circle) are set by a click on the map, the **X** buttons next to them delete them. In between you can place **waypoints** (button **Waypoint**: every click adds one, right click ends): the enemies walk from the spawn point through the waypoints in their order to the goal; the pathfinding does the rest. A waypoint you click onto the drawn (yellow) line goes in between the two points of that line, otherwise behind the nearest point of the route. **Ctrl + hold the left mouse button** over a waypoint moves it (placing and moving spawn point, goal and waypoints can be undone with Ctrl+Z and redone with Ctrl+Y like everything else), **Del** over a waypoint removes it, the X next to the button removes all.
- **Enemies allowed through**, then **Waves** (number: buttons, or click the number and type) and one row per wave: the wave number (fixed), factions (three toggle buttons with the faction symbols, several possible), tech T1-T3 (toggles), type **V** vehicles / **B** bots / **H** hovercraft (toggles; ships are not used), count, **gap** in seconds after the previous wave (wave 1: after the start, so it is the grace period) and **HP %** (strength, 100 = normal). In every group at least one choice stays on; the units are picked at random among all that match (pure anti-air units are left out, they cannot hit the ground). The mouse wheel scrolls long tables.
- With **Tower Defense** ticked the checkbox and the **TD** button in the button column turn green (also on the Place and Generate pages). Long tooltips wrap into several lines.
- **Start test** (green button at the very bottom of the TD page) runs the waves in the editor. Without spawn point and goal it only shows a red message above the button. The state before is saved as `_beforeplay` first. The player's metal and energy are set to the **start metal and energy of the level** (page I, default 1000 each; storage the same, at least 1000) for the test, so it is realistic; after Stop the editor's huge amounts are back. **Stop** (the button's name while it runs, **Reset** when the level is won or lost) ends the waves and brings that state back, so towers that got destroyed are there again. The units appear one after the other, walk the path, a kill pays the unit's metal and energy, an enemy that reaches the goal counts as through; too many through = lost, all waves beaten = won; the status shows at the top of the screen. Wave units are not saved with the level.
- **Restrictions** (above the tower list): choose a faction and a tech level, the towers (armed buildings on land) are shown with picture, 3D model and cost like in the unit list. A **red X** in the upper right corner of a tile forbids the tower: it gets a big red X, and while the game runs (Start test, later in the scenario) the player cannot build it; click the X again to allow it. The editor itself can always place every tower. The forbidden towers are saved in the level (`banned` in the section `towerdefense`). Towers can always be built. Two toggle buttons, both on by default: **Economy** (on = the player can also build metal extractors, solar, wind and other power plants, storage; they appear in the list too, so you can forbid single ones; off = towers only) and **Fog of war** (on = the player can build radars, shown in the list; off = no radars and the whole map is visible; the editor always shows the whole map). Below the faction buttons a row of categories (**Towers**, with Economy on also **Economy**, with fog also **Radars**) sorts the list; only tech levels that have entries are shown. A click on a tile of the list arms placing it like on the Place tab (Ctrl, Alt, Shift work as there); the list scrolls with the mouse wheel. A red X on a tech button (T1, T2, T3) forbids every structure of that level. At the start of the test the commander of the player is removed (the builders are placed by the level; Stop brings everything back).
- The waves run in the gadget `td_waves.lua`. **In a scenario package** (start menu key 3, see below) a level with Tower Defense switched on is packed with everything: waves, route, forbidden towers and tech levels, restrictions, fog of war and the indestructible walls. The recipient's `Start Scenario.bat` builds a small extra game "Tower Defense Scenario" next to the official game (it only adds the gadget, see `scenario\README.md`).

## Capture the Flag
The button **CF** (in the button column at the right, below **TD**) opens the Capture the Flag page. Flags (the silver pods of the scavengers) lie at flag points on the map; units pick them up by getting close, carry them to the collection point of their team and earn metal for it. It is meant for human against human (computer opponents do not play it).
- Tick **Capture the Flag** to mark the level; with it ticked the button **CF** turns green. Tower Defense and Capture the Flag exclude each other: ticking one switches the other off (both can be off). All settings are saved with the level in an own section `capture` of the level file.
- **Flags:** *Own flags per team* (every team has its own flags, only the other teams take them) or *Neutral flags* (every team may take every flag); exactly one of the two is on.
- **Flags always visible on the map** (box, on by default): the flags are shown on the whole map and the minimap, also without radar or a unit nearby. Off: only what a unit sees. On the minimap every flag is a small square in the color of its team (light grey = neutral) and every collection point has a ring in its team color.
- **Income (metal per second):** every flag that lies at the collection point of a team pays that team the amount every second (click the field, type a number, Enter). A flag that is carried or was stolen pays nothing, there is no one-time reward and no experience. A delivered flag stays at the collection point; units of other teams can steal it from there, it does not jump back to its flag point.
- **Flags a team must hold at once to win** (0 = the level never ends), **capture radius** in Elmo (pick up, deliver and bring back) and the time after which a **dropped flag** goes back to its flag point (0 = the default: it stays where the carrier was destroyed until a unit takes it). **The unit that carries a flag cannot shoot** (its weapons are switched off until it delivers or dies).
- **Places on the map:** choose the team in the strip at the left, then **Collection point** (click the place on the map; one per team, a new one replaces it) and **Flag point** (every click adds one; with *Own flags* the flag belongs to the chosen team, so place the flags of a team in its own area and neutral flags in the middle). Right click ends the mode, **Del** over a point removes it, **Alt + drag** moves a point (the point under the mouse gets a second ring), **Ctrl+Z / Ctrl+Y** undo and redo every change of the points, the **X** buttons delete the collection point of the chosen team or all flag points (with *Own flags*: those of the chosen team). The rings show the radius: thick = collection point, thin = flag point, in the color of the team (white = neutral).
- A team's own units can bring a dropped flag of their team back by touching it. **Own flags:** a team whose flags all stay at the collection points of the others has lost: all its units blow up (and what it builds later), the last team standing wins. A unit carries one flag at a time; air units and units in a transporter can carry a flag too; if the carrier is destroyed (own or enemy) the flag is dropped there and lies there until somebody takes it (or the return time is over).
- **Start test** (green button at the bottom of the page) runs the game in the editor, **Stop** brings the level back to the state before (saved as `_beforeplay` first). The score of every team is shown at the top of the screen. The flags and the collection points are neutral, indestructible units of the game (the editor does not save them).
- The game runs in the gadget `ctf_game.lua`. **In a scenario package** (start menu key 3) a level with Capture the Flag switched on is packed with its settings (see `scenario\README.md`). A level can have Tower Defense **and** Capture the Flag: the package then holds both and the player chooses at the start which one to play; the other mode is left out (the corridors of Tower Defense disappear when Capture the Flag is chosen).

## Making a scenario from it
In the game itself: the button **I** in the button column at the far right next to the menu opens the scenario info: title, author, summary, briefing (Shift+Enter = new line), role of each team, AI behavior, win condition, start metal/energy and ID. Click text fields and type (Enter done, Esc cancel), the other fields change with every click. The info is written when the level is saved; there is no save button on this page (Ctrl+S saves). The scenario builder does the rest (see below).
In the start menu **key 3** (create a scenario package from a level): choose a level; the script lists the values stored in the level and asks only for the title (Enter keeps it) and the name (ID) of the scenario, then builds a scenario that others can play with the official BAR (folder and zip in `scenario\scenarios`; an existing scenario of that name is only overwritten after a question). The info (title, briefing, roles, tech, AI, win condition, resources, grace period, ID) is stored in the level and changed in the editor with the I button. Details in `scenario\README.md`.
