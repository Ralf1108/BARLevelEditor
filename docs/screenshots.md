# Screenshots of the README

Notes on what each picture shows, so they can be retaken after a change of the layout.

**Rules for all Level Editor pictures**
- They show the **whole widget**: the strip at the left of the menu (W, DL, DR, DC, L, R, S, N, teams, G), the menu, the button column at the right (V, O, I, T, ?, P, G, A, TD, CF, RF, XL, XR, XC, FX, FD) and, where the mouse pointer rests on a tile, the **3D preview** left of the strip with the **info lines** below the menu.
- Where it matters the picture also shows a part of the map with the result of the action (generated units, a maze, a corridor with route and towers, ...).
- Taken in a window of 3000 x 1500 pixels (isolated test instance, see below), cut to x 940 ... 3000, y 0 ... 1260 (the chat lines at the top left are part of the cut on purpose) and scaled to 1600 pixels width, JPEG quality 88.
- Map: "Hooked 1.1" for the older pictures, since 2026-10-28 "Full Metal Plate 1.7" (flat; see below), Armada, team 0.

**How they were taken:** an isolated test instance of the game (own write folder, own settings with a framed window, own copy of the extra game) so the normal game stays untouched; a temporary widget set the scenes up through the widget (clicks on buttons and on the map) and took the screenshots. The scripts are not part of the repository, except the Arena pictures: `LevelEditor\test-data\tools\arena_test.ps1 -Shots` (widget `zz_arena_shots.lua`) takes both and can run next to a running game (`-AlongsideGame`).
